Windows Executable Build Guide

🎉 What You'll Build: A complete, standalone Windows installer that includes frontend, backend, database, and all runtimes. Users install and run offline immediately!
1

Download & Install Prerequisites

Install these programs on your Windows computer (one-time setup):

  • Node.js 18+ from nodejs.org
  • Python 3.9+ from python.org (Check "Add to PATH"!)
  • Git from git-scm.com
  • MongoDB ZIP from mongodb.com (Windows x64 ZIP)
⚠️ Important: When installing Python, you MUST check "Add Python to PATH" checkbox!
2

Prepare MongoDB

Extract the MongoDB ZIP and set it up:

Extract - Unzip the downloaded MongoDB file
Find bin folder - Inside the extracted folder
Copy - Copy the entire bin folder to: /app/mongodb/bin/
Verify - Check that mongod.exe is at: /app/mongodb/bin/mongod.exe
3

Check Your System

Verify everything is ready:

python check_prerequisites.py

This script checks:

  • Node.js and npm are installed
  • Python and pip are installed
  • Git is available
  • MongoDB is prepared
  • You have enough disk space
  • All required files are present
4

Build the Executable

Method 1: Automatic (Easiest)

Just double-click this file:

build_windows_exe.bat

Or run in Command Prompt:

cd /app build_windows_exe.bat

Method 2: Manual (Step-by-step)

# Build Backend cd /app/backend pip install pyinstaller pip install -r requirements.txt python build_backend.py # Build Frontend cd /app/frontend npm install -g yarn copy electron-package.json package.json yarn install yarn add electron-is-dev yarn build yarn electron:build
5

Build Timeline

Here's what to expect during the build:

0-10 min: Backend compilation with PyInstaller
10-20 min: React frontend build
20-35 min: Electron packaging and installer creation
⏱️ Total Build Time: 20-35 minutes. Be patient, especially on first build!
6

Get Your Installer!

After successful build, you'll find your installers at:

/app/frontend/dist/Ananta POS-Setup-2.0.1.exe (~200-300 MB) /app/frontend/dist/Ananta POS-Portable-2.0.1.exe (~200-300 MB)

Test Your Build

🚨 Common Issues & Quick Fixes

  • ❌ "Python not found"
    → Reinstall Python and check "Add to PATH"
  • ❌ "Node not found"
    → Reinstall Node.js, restart Command Prompt
  • ❌ Backend build fails
    → Run: pip install -r requirements.txt --force-reinstall
  • ❌ "Access Denied"
    → Run Command Prompt as Administrator
  • ❌ Build takes forever
    → Be patient, Electron downloads tools (first time takes longest)
